# Online Retail Sales Analysis

# Project Overview
This project analyzes an online retail dataset containing over 500,000 transactions from customers across more than 30 countries. The goal of the analysis was to identify trends in sales performance, customer behavior, and product performance using SQL and Tableau.

The project includes data cleaning, feature engineering, exploratory data analysis, customer segmentation, and an interactive Tableau dashboard highlighting key business insights. 

# Tools Used
- PostgreSQL: Data cleaning, transformation, and exploratory analysis
- SQL: Aggregations, CTEs, customer segmentation, and business analysis
- Tableau: Data visualization and interactive dashboard creation
- Git/GitHub: Version control and project documentation

# Key Insights
- November 2011 generated the highest monthly revenue.
- Thursday had the highest number of orders.
- Top-level customers (over $10,000 spend) accounted for 40.1% of the customer revenue.
- Repeat customers account for 77.7% of total revenue.
